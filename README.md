# THM-Billing
Overview

This write-up documents my approach to the Billing room on TryHackMe.

The objective of the room was:

Gain a shell, find the way and escalate your privileges.

The assessment involved:

Network reconnaissance
Web application identification
Vulnerability identification
Exploitation of MagnusBilling
Obtaining an initial shell
Linux privilege enumeration
Sudo misconfiguration analysis
Fail2Ban abuse
Privilege escalation to root

Note: This write-up is for educational purposes and documents activity performed against the authorized TryHackMe lab environment.
